# Twimark 現行要件

X・note・Qiitaの投稿と記事を、カテゴリ・サブカテゴリ付きのカードで見るブックマークツール。PortalのTipsの使い勝手を単独のツールにしたもの。

## 構成

- 一覧の画面と API: Cloudflare Workers の1つの Worker `twimark`（`https://twimark.ho-service.workers.dev`）。画面は素のHTML・JS・CSSで静的アセットとして返し、`/api/*` だけ Worker（`src/worker`）が受ける。公開は手元のログイン済みの wrangler から行う。
- データ: Cloudflare D1（`twimark`）。ブックマークは1件1行。ログインした利用者だけが読み書きできる。
- 利用者: 最初の1人が管理者（`owner`）になり、登録は閉じる。ほかの人は、管理者が「設定」の「招待」で作った招待リンク（`/?invite=<値>`、1回きり、3日で切れる、取り消せる）からだけ登録できる（`member`）。ブックマーク・カテゴリ・パスキー・端末のトークンは人ごとに別で、ほかの人のものは見えない。
- ログインの履歴: パスワードとパスキーのログインの成功と失敗（ロック中の試みを含む）を、その ID の利用者の分として30日残す。日時、方法、Web かアプリか、失敗の code、IP、国、User-Agent。ない ID への試みは残さない。それぞれ自分の分だけを一覧の「設定」で見る（`GET /api/login-events`）。
- ログイン: ID とパスワード。パスキーを任意で足せ、パスキーがある ID ではログインのときにパスキーを先に求める。パスワードでのログインも残す。パスワードの失敗が同じ ID で15分に5回に達したら、15分ログインさせない。
- 認証: 一覧の画面は Cookie（`__Host-twimark`、HttpOnly・Secure・SameSite=Strict、30日）。拡張とアプリは端末のトークン（Bearer、365日）。どちらも使うたびに期限を延ばす。D1 には SHA-256 だけを置く。
- 端末のトークンの種類（`sessions.app`）: アプリのトークン（アプリへの受け渡しと、`device` 付きのログインで作る）は、データの読み書きと設定の操作（パスワードの変更、パスキーの一覧と削除、端末のトークン、招待、ログインの履歴）ができる。パスキーの登録は WebAuthn がそのオリジンのブラウザでしか動かないので、web のセッションだけ。拡張のトークン（設定で発行する）はデータの読み書きだけ。`0003` より前のトークンは拡張と同じ扱い。
- 拡張: Chrome/Edge（Manifest V3）。
- iPhoneアプリ: `src/mobile` の Expo（SDK 57、App Store 版 Expo Go に合わせる）。App Store には出さず、mainへのpushで EAS Update の `main` チャンネルへ公開し、Expo Go で開く。Expo Go は、サインインしたアカウントが持つプロジェクトの更新だけを開く。

## データの形

`GET /api/data` は `{ categories: string[], subcategories: { [カテゴリ]: string[] }, bookmarks: Bookmark[] }`。`Bookmark` は `id`（`x:<ID>`・`note:<キー>`・`qiita:<ID>`）、`site`、`url`、`author { name, handle }`、`postedAt`、`title`（記事）、`text`、`photos[{ url }]`、`videos[{ thumbnail }]`、`category`、`subcategory`（なければ null）、`savedAt`。

- カテゴリは30個まで、サブカテゴリは1つのカテゴリに30個まで、名前はどちらも20文字まで。サブカテゴリの名前は同じカテゴリの中で重複させない。既定のカテゴリはPortalのTipsと同じ6つで、登録のときに作る。
- 削除したカテゴリのブックマークは消さず、「未分類」に出る。そのカテゴリのサブカテゴリは消える。
- 削除したサブカテゴリのブックマークは、カテゴリの直下に戻る。
- 追加の下見は `POST /api/meta { url }`（ログインした人だけ）。`parseUrl` が受ける URL だけを、決まった取得先（fxtwitter、`note.com`、`qiita.com`）から8秒・2MBまでで取り、`{ item }`（取れなければ null）を返す。一覧の画面とアプリが使う。拡張は自分で取得する。
- 変更は `POST /api/ops { op, args }` で、操作のあとのデータを返す。操作は `add`、`remove`、`setCategory(id, category, subcategory)`、`addCategory`、`removeCategory`、`sortCategories`、`addSubcategory`、`removeSubcategory`、`sortSubcategories`、`nestCategory(name, parent)`、`promoteSubcategory(category, name)`、`moveSubcategory(from, name, to)`、`setAccent(色 | null)`、`setAccentText(色 | null)`、`setCategoryColor(カテゴリ, 色 | null)`。`/api/data` は `accent`・`accentOn`（アクセントの地の上の文字の色）と `categoryColors`（色を決めたカテゴリだけ）も返す。
- カテゴリをほかのカテゴリの下に入れる（`nestCategory`）と、そのカテゴリと、持っていたサブカテゴリが、入れ先のサブカテゴリの後ろに同じ段で並ぶ。ブックマークは `(入れ先, カテゴリ名)` か `(入れ先, サブカテゴリ名)` へ移る。サブカテゴリをカテゴリに戻す（`promoteSubcategory`、一番後ろ）と、ブックマークはその直下へ移る。サブカテゴリはほかのカテゴリへ移せる（`moveSubcategory`）。同じ名前がもうあれば1つに合わせ、上限を超えるなら何も変えずに断る。

## 対象のURL

| サイト | URL | 取得元 |
|---|---|---|
| X | `https://x.com/<handle>/status/<ID>`（`twitter.com`、`mobile.twitter.com`、`/i/web/status/<ID>` も） | fxtwitter |
| note | `https://note.com/<ユーザー>/n/<キー>` | 記事のHTMLのJSON-LDとOGP |
| Qiita | `https://qiita.com/<ユーザー>/items/<ID>` | 記事のHTMLのJSON-LDとOGP |

取得できなかったときは本文を貼り付けて保存する。要約は持たない。

## 拡張の追加の入口

1. ツールバーのボタン（開いているタブ）
2. 右クリック（対象のリンク、対象のページ）
3. 共有メニューに差し込んだ「Twimarkに追加」（Xのポストの共有メニュー、noteの記事の共有メニューと記事下の並び、Qiitaの記事の共有の並び）

どれも追加の画面を開き、カテゴリとサブカテゴリ（前回選んだ組）を選んで追加する。保存済みなら追加させない。

## 画面の作り（一覧の画面とアプリで共通）

- Apple の Human Interface Guidelines に沿う。値（色、文字の大きさ、角丸、動き）は `src/shared/theme.js` の1か所。一覧の画面は `build.mjs` が書き出す `tokens.css`、アプリは `src/mobile/theme.js` から使う。
- 色: 地・面・文字・区切りは iOS のシステムの色（グループ表示）。ライトとダークは端末の設定に従う。
  - アクセントは利用者が選ぶ（`users.accent`、既定は抹茶の黄緑 `#8DB255`）。`theme.js` の `accentSet` が、地に塗る色・その上の文字・面の上の文字（色相のまま明るさを変えて 4.5:1 以上）・淡い地・その上の文字を作る。
  - アクセントの地の上の文字の色も選べる（`users.accent_on`、NULL は白か黒の読みやすいほう）。`accentSet(hex, on)` の `on` がその色になる。アクセントを既定に戻しても残る。
  - カテゴリの色は、決まった11色（くすみパステル）か自由な色（`categories.color`、NULL は並び順）。自由な色は `toneSet` が、ライトとダークの [文字, 地] を 4.5:1 以上で作る。
- 縦長（一覧の画面の `(max-width: 767px), (orientation: portrait)`、とアプリ）は同じ作り。
  - 上のバーは出さない（送っても）。内容は安全領域の上端から始まり、大きな見出しは内容と一緒に送る。
  - 下の真ん中に、丸い形の中を3つに分けたタブ（一覧・カテゴリ・設定。アイコンと名前）を浮かべる（下の安全領域から 4、安全領域のない画面では 12）。選んでいるタブはアクセントの薄い地の札を後ろに敷き、選び直すと札が横へすべる。今の「一覧」をもう一度押すと最上部へ送る（アプリはステータスバーを押しても）。Web の再読み込みはカテゴリの画面の下。
  - 右下、タブの一段上（12 空ける）に丸い「＋」（一覧だけ）で追加のシート。
  - どの画面でも送り始めたら、タブと「＋」を 0.15 秒のフェードで消し（消えている間は押せない）、止まって 0.25 秒で出す。カードを持ち上げている間も消す。
  - 一覧: 検索欄（右端にサイトのフィルターのアイコン）、カテゴリのチップ（すべて・各カテゴリ・未分類、件数と色）、選んだカテゴリのサブカテゴリのチップ、カード。読み込み中はカードの形の淡い四角。
  - サイトのフィルター: アイコンを押すとメニュー（すべてのサイト・X・note・Qiita。今の項目にチェック）。絞り込んでいる間はアイコンをアクセントの文字の色にして点を付け、チップの並びの最後に外すチップ（「X ×」など）を出す。
  - カード: 画像は上に大きく（複数は2列、1枚は高さを抑えて全幅、ないときは出さない）、カテゴリの札（`カテゴリ › サブカテゴリ`、押すとカテゴリの変更）・サイト・「…」、タイトル、本文、作者と日付。本文は5行を超えたら折りたたみ、「続きを見る」でその場で開く（「閉じる」で戻す）。押すと元のページ。「…」か強く押す（3D Touch の force が 0.6 を超える。アプリと iPhone の Safari。押す強さに合わせて少し縮む）でカテゴリの変更・元のページ・削除（確認つき）。縦長は1列、600px 以上の縦長は2列。
  - カードの長押し（0.4 秒、その間に 10px 動いたら送り）: カードは薄く残り、写しが指に付いて持ち上がり、下からカテゴリの置き場（画面の 45% まで、札を2列）がせり上がる。今のカテゴリの札は「今の場所」で置き先にしない。サブカテゴリを持つ札に 0.6 秒重ねると、中の札（「‹ カテゴリ」、直下、サブカテゴリ）に替わる。置き場の上端・下端 48px では置き場の中を送る。札の上で離すと写しが札へ縮んで消えてそこへ移し、外で離すと写しが戻る。「未分類」へは移せない（保存の操作がない）。
  - カテゴリ: グループ表示のリスト（すべて、カテゴリとサブカテゴリの件数と色、未分類）。行を押すとその絞り込みの一覧へ。Web は行の右クリックで、押した場所に編集のメニュー（カテゴリ: サブカテゴリを追加・色を変える・ほかのカテゴリの下に入れる・削除。サブカテゴリ: カテゴリにする・ほかのカテゴリへ移す・削除。Shift を押しながらはブラウザのメニュー）。「編集」で ⊖ の削除（確認つき）、右のつまみのドラッグでの並べ替え（サブカテゴリは同じカテゴリの中。キーボードは ↑↓、読み上げは「上へ」「下へ」）、「サブカテゴリを追加」「カテゴリを追加」。動かしている行は指に付いて動き（カテゴリならそのサブカテゴリの行も一緒に）、ほかの行はずらさず入る位置に線を出す。動かしている行がほかのカテゴリの行と、その行の高さの半分以上重なったら入れ先にし、離すとその下に入る（カテゴリはサブカテゴリになり、サブカテゴリは移る）。Web はマウスで名前の行を 6px 以上動かしても同じドラッグになり、横長のサイドバーでは「編集」していなくても動かせる（押して離すだけなら今までどおり）。サブカテゴリを動かす間だけ、画面の下に「カテゴリにする」の置き場を出す。編集中は色の点を押すとカテゴリの色を選べる。子を持つカテゴリを入れるときだけ確認を出す。編集中に名前を押すと、同じことをメニューでできる。
  - 設定: アカウント、外観（アクセントの色、アクセントの文字の色）、パスキー、パスワード、拡張・アプリのトークン、招待（管理者だけ）、ログインの履歴（下の画面）、ログアウト。
  - 色を選ぶシート: 見本、色を選ぶ部分（Web は `<input type="color">`、アプリは彩度と明るさの四角と色相の帯）、RGB と `#RRGGBB` の欄、よく使う色、「既定に戻す」（カテゴリとアクセントの文字は「自動」）。カテゴリのときは決まった11色、アクセントの文字のときは白と黒も出す。アクセントとその文字の組が 4.5:1 に届かないときは見本の下に注意を出す（保存はできる）。アプリでは、見本・四角・色相の帯（押せる高さ 44）をシートの上側に固定し、残りだけを送る。色見本の並びは押したまま指を滑らせて選べ（決まった色・白黒は離したときに保存して閉じる）、なぞっている間は送りを止める。シートは下へなぞっても閉じない。
  - 追加のシート: URL の欄、「クリップボードから貼り付け」、下見（`/api/meta`）、取得できなかったときの本文の欄、カテゴリとサブカテゴリのチップ（前回選んだ組）。保存済みなら追加させない。
- 横長の一覧の画面: 左のサイドバー（カテゴリの行と「編集」、再読み込み、設定）、上の検索、カードのメイソンリー（`columns: 4 300px`）、検索の欄の右に「＋ 追加」。「編集」中のサイドバーは行を 40px にし、削除・色・名前の間とカテゴリの塊の間をあける。シートは画面の中央に出す。
- 動き: 押したときに縮む、シートは下から、下のタブと「＋」のフェード、カードの持ち上げ、並びの変化（Web は View Transitions、アプリは LayoutAnimation）、アプリの触覚。動きを減らす設定では、移動と拡大縮小をやめる。

## 一覧の画面

- ログインの前: 登録（`users` が0件のとき）かログインの画面だけを出す。ログインは ID を入れて「次へ」→ パスキーがあればパスキー、なければパスワード。
- アプリへの受け渡し: `?app=<戻り先>`（`exp:` か `twimark:` だけ）付きで開くと、ログインのあとに確認を出し、「渡す」でアプリのトークンを作って `<戻り先>#token=<値>` へ移る。
- アプリのパスキーの追加: `?tab=settings&passkey=add&app=<戻り先>` で開くと、ログインのあと設定に「パスキーを追加」を出し、作れたら `<戻り先>#passkey=added` へ移る（トークンは渡さない）。
- URL のクエリ: 絞り込み（`?category=&sub=`、`?uncategorized`、`?site=`）、検索語（`?q=`）、タブ（`?tab=categories|settings`、`&page=history`）。タブと画面の移動は戻るボタンで戻る。`/?add=<URL>` は追加のシートをその URL で開く。
- 検索は NFKC でそろえ、空白区切りの語をすべて含む（サブカテゴリの名前も対象）。窓に戻ったときに1分たっていれば読み直す。
- PWA: `manifest.webmanifest`（`display: standalone`、192・512・512 maskable のアイコン）と `apple-touch-icon`（180）。Safari の「ホーム画面に追加」で全画面で開く。サービスワーカーとオフラインは持たない。
- アイコン: ファビコン（SVG・32px の PNG）、PWA、アプリ（1024）、拡張（16・32・48・128）は `design/icon/make-icon.jsx`（Illustrator）が1つの絵から書き出す。

## iPhoneアプリ

- ログインしていなければログインだけを出す。「ブラウザでログイン」で一覧の画面をアプリ内の認証の画面（`openAuthSessionAsync`）で開き、受け渡されたアプリのトークンを受け取る。パスキーが使える。予備に ID とパスワードだけのログインを持つ（`/api/login/password` に `device` を付ける）。
- 一覧は引っぱって再読み込み。設定のパスキーの追加は、Web の設定をアプリ内の認証の画面で開いて行う。設定にはアプリだけのもの（ショートカットの URL、接続の確認、Web の一覧）もある。
- 前の版のトークンで設定が `web_only` で断られたら、ログインし直すよう出す。
- 共有シートのショートカットが `<アプリの URL>/--/add?url=<エンコードしたポストの URL>` でアプリを開くと、追加のシートを出す。アプリの URL は「設定」に出す（Expo Go の開き方で変わるので、決め打ちしない）。
