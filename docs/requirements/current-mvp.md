# Twimark 現行要件

X・note・Qiitaの投稿と記事を、カテゴリ・サブカテゴリ付きのカードで見るブックマークツール。PortalのTipsの使い勝手を単独のツールにしたもの。

## 構成

- 一覧の画面と API: Cloudflare Workers の1つの Worker `twimark`（`https://twimark.ho-service.workers.dev`）。画面は素のHTML・JS・CSSで静的アセットとして返し、`/api/*` だけ Worker（`src/worker`）が受ける。公開は手元のログイン済みの wrangler から行う。
- データ: Cloudflare D1（`twimark`）。ブックマークは1件1行。ログインした利用者だけが読み書きできる。
- 利用者: 最初の1人が管理者（`owner`）になり、登録は閉じる。ほかの人は、管理者が「設定」の「招待」で作った招待リンク（`/?invite=<値>`、1回きり、3日で切れる、取り消せる）からだけ登録できる（`member`）。ブックマーク・カテゴリ・パスキー・端末のトークンは人ごとに別で、ほかの人のものは見えない。
- ログインの履歴: パスワードとパスキーのログインの成功と失敗（ロック中の試みを含む）を、その ID の利用者の分として30日残す。日時、方法、Web かアプリか、失敗の code、IP、国、User-Agent。ない ID への試みは残さない。それぞれ自分の分だけを一覧の「設定」で見る（`GET /api/login-events`）。
- ログイン: ID とパスワード。パスキーを任意で足せ、パスキーがある ID ではログインのときにパスキーを先に求める。パスワードでのログインも残す。パスワードの失敗が同じ ID で15分に5回に達したら、15分ログインさせない。
- 認証: 一覧の画面は Cookie（`__Host-twimark`、HttpOnly・Secure・SameSite=Strict、30日）。拡張とアプリは、一覧の画面で発行する端末のトークン（Bearer、365日）。どちらも使うたびに期限を延ばす。D1 には SHA-256 だけを置く。
- 拡張: Chrome/Edge（Manifest V3）。
- iPhoneアプリ: `src/mobile` の Expo（SDK 57、App Store 版 Expo Go に合わせる）。App Store には出さず、mainへのpushで EAS Update の `main` チャンネルへ公開し、Expo Go で開く。Expo Go は、サインインしたアカウントが持つプロジェクトの更新だけを開く。

## データの形

`GET /api/data` は `{ categories: string[], subcategories: { [カテゴリ]: string[] }, bookmarks: Bookmark[] }`。`Bookmark` は `id`（`x:<ID>`・`note:<キー>`・`qiita:<ID>`）、`site`、`url`、`author { name, handle }`、`postedAt`、`title`（記事）、`text`、`photos[{ url }]`、`videos[{ thumbnail }]`、`category`、`subcategory`（なければ null）、`savedAt`。

- カテゴリは30個まで、サブカテゴリは1つのカテゴリに30個まで、名前はどちらも20文字まで。サブカテゴリの名前は同じカテゴリの中で重複させない。既定のカテゴリはPortalのTipsと同じ6つで、登録のときに作る。
- 削除したカテゴリのブックマークは消さず、「未分類」に出る。そのカテゴリのサブカテゴリは消える。
- 削除したサブカテゴリのブックマークは、カテゴリの直下に戻る。
- 変更は `POST /api/ops { op, args }` で、操作のあとのデータを返す。操作は `add`、`remove`、`setCategory(id, category, subcategory)`、`addCategory`、`removeCategory`、`sortCategories`、`addSubcategory`、`removeSubcategory`、`sortSubcategories`。

## 対象のURL

| サイト | URL | 取得元 |
|---|---|---|
| X | `https://x.com/<handle>/status/<ID>`（`twitter.com`、`mobile.twitter.com`、`/i/web/status/<ID>` も） | fxtwitter |
| note | `https://note.com/<ユーザー>/n/<キー>` | 記事のHTMLのJSON-LDとOGP |
| Qiita | `https://qiita.com/<ユーザー>/items/<ID>` | 記事のHTMLのJSON-LDとOGP |

取得できなかったときは本文を貼り付けて保存する。要約は持たない。

## 拡張の追加の入口

1. ツールバーのボタン（開いているタブ）
2. 右クリック（対象のリンク、対象のページ）
3. 共有メニューに差し込んだ「Twimarkに追加」（Xのポストの共有メニュー、noteの記事の共有メニューと記事下の並び、Qiitaの記事の共有の並び）

どれも追加の画面を開き、カテゴリとサブカテゴリ（前回選んだ組）を選んで追加する。保存済みなら追加させない。

## 一覧の画面

- ログインの前: 登録（`users` が0件のとき）かログインの画面だけを出す。ログインは ID を入れて「次へ」→ パスキーがあればパスキー、なければパスワード。
- アプリへの受け渡し: `?app=<戻り先>`（`exp:` か `twimark:` だけ）付きで開くと、ログインのあとに確認を出し、「渡す」で端末のトークンを作って `<戻り先>#token=<値>` へ移る。
- サイドメニュー: すべて、カテゴリ（件数、色、ドラッグと ↑↓ キーでの並べ替え、サブカテゴリの追加、削除）、その下のサブカテゴリ（件数、同じカテゴリの中での並べ替え、削除）、未分類、カテゴリの追加
- 検索（NFKCでそろえ、空白区切りの語をすべて含む。サブカテゴリの名前も対象）、サイトの絞り込み。絞り込み（`?category=&sub=`）と検索語はURLのクエリに残す
- カード: カテゴリ（`カテゴリ › サブカテゴリ`）、サイト、画像、タイトル、本文（6行で折りたたみ）、作者、日付、元のページへのリンク、カテゴリとサブカテゴリの変更、削除
- 設定: パスキーの追加・削除、パスワードの変更（ほかのセッションと端末のトークンはすべて消える）、端末のトークンの発行・取り消し、ログアウト
- 画面からの追加はない（`docs/backlog.md` の B-001）

## iPhoneアプリ

- 画面は下のタブの「一覧」「追加」「カテゴリ」「設定」。ログインしていなければ「設定」のログインだけを出す。
- ログイン: 「ブラウザでログイン」で一覧の画面をアプリ内の認証の画面（`openAuthSessionAsync`）で開き、受け渡された端末のトークンを受け取る。パスキーが使える。予備に ID とパスワードだけのログインを持つ（`/api/login/password` に `device` を付けて端末のトークンを受け取る）。
- 一覧: カテゴリ（すべて、件数と色、未分類）、選んだカテゴリの下のサブカテゴリ、サイトの絞り込み、検索（一覧の画面と同じ決まり。`src/shared/view.js`）、引っぱって再読み込み。カードは一覧の画面と同じ項目で、カテゴリとサブカテゴリの変更、削除（確認つき）ができる。
- カテゴリ: カテゴリとサブカテゴリの追加、↑↓ ボタンでの並べ替え、削除（確認つき）。
- 追加の入口:
  1. Xアプリの共有シートに置いたショートカット。`<アプリの URL>/--/add?url=<エンコードしたポストの URL>` でアプリを開くと「追加」に移る。アプリの URL は「設定」に出す（Expo Go の開き方で変わるので、決め打ちしない）
  2. 「追加」の URL の欄と「クリップボードから貼り付け」（Xの「リンクをコピー」から）
- 追加は拡張と同じく、カテゴリとサブカテゴリ（前回選んだ組）を選んで追加する。保存済みなら追加させない。取得できなかったときは本文を貼り付けて保存する。
