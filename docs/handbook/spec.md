## 何のためのものか

X・note・Qiita の投稿と記事を、カテゴリ・サブカテゴリ付きのカードで見るブックマークツール。Portal の Tips の使い勝手を単独のツールにしたもの。一覧は Cloudflare Workers の画面で、追加は Chrome/Edge の拡張機能か iPhone アプリ（Expo Go）から行う。ブックマークは利用者1人だけが見られる。

## 画面と機能

- **ログイン**: ID とパスワード。パスキーを任意で足せ、パスキーがある ID ではパスキーを先に求める（「パスワードでログイン」も残る）。最初の1人だけが登録でき、そのあと登録は閉じる。パスワードの失敗が15分に5回に達すると15分止める。
- **一覧の画面**: サイドメニュー（すべて、カテゴリとその下のサブカテゴリの件数と色、未分類、カテゴリ・サブカテゴリの追加・並べ替え・削除）、検索（NFKC でそろえ、空白区切りの語をすべて含む）、サイトの絞り込み。絞り込みと検索語は URL のクエリに残る。
- **カード**: カテゴリ（`カテゴリ › サブカテゴリ`）、サイト、画像、タイトル、本文（6行で折りたたみ）、作者、日付、元ページへのリンク、カテゴリとサブカテゴリの変更、削除。
- **設定**: パスキーの追加・削除、パスワードの変更、拡張・アプリの端末のトークンの発行・取り消し、ログアウト。
- **拡張からの追加**: ツールバーのボタン、右クリック、共有メニューに差し込んだ「Twimarkに追加」の3経路。カテゴリとサブカテゴリ（前回選んだ組）を選んで追加する。保存済みなら追加させない。取得できなかったときは本文を貼り付けて保存する。拡張は一覧の画面で発行した端末のトークンで認証する。
- 画面からの追加は無い（課題 B-001）。
- **iPhone アプリ**: 下のタブの一覧・追加・カテゴリ・設定。一覧の画面と同じデータで、絞り込み・検索、カテゴリとサブカテゴリの変更・削除、カテゴリとサブカテゴリの追加・↑↓ での並べ替え・削除ができる。ログインは一覧の画面をアプリ内の認証の画面で開いて行い（パスキーが使える）、予備に ID とパスワードだけのログインがある。
- **アプリへの追加**: X アプリの共有シートに置いた iOS のショートカットが `<アプリの URL>/--/add?url=<ポストの URL>` でアプリを開く。X の「リンクをコピー」からの貼り付けでも追加できる。カテゴリ・保存済み・本文の貼り付けの扱いは拡張と同じ。

## 対象のURLと取得元

| サイト | URL | 取得元 |
|---|---|---|
| X | `x.com/<handle>/status/<ID>`（twitter.com なども） | fxtwitter |
| note | `note.com/<ユーザー>/n/<キー>` | 記事の HTML の JSON-LD と OGP |
| Qiita | `qiita.com/<ユーザー>/items/<ID>` | 記事の HTML の JSON-LD と OGP |

要約は持たない。

## データの持ち方

- 正本は Cloudflare D1 の `twimark`。ブックマークは1件1行で、カテゴリ、サブカテゴリ、利用者、パスキー、セッション（Cookie と端末のトークン）も D1 に置く。
- 1件は `id`（`x:<ID>` など）、サイト、URL、作者、投稿日、タイトル、本文、画像・動画のサムネイル、カテゴリ、サブカテゴリ（任意）、保存日。
- カテゴリは30個まで、サブカテゴリは1つのカテゴリに30個まで、名前は20文字まで。既定のカテゴリは Portal の Tips と同じ6つ。
- 削除したカテゴリのブックマークは「未分類」に出て、そのサブカテゴリは消える。削除したサブカテゴリのブックマークはカテゴリの直下に戻る。
- 読み書きはログインした利用者だけ。リポジトリにはブックマークを置かない。

## しないこと

- 要約、画面からの追加、ストアでの拡張の公開
- 複数の利用者、パスワードの再設定のメール、カテゴリ・サブカテゴリの名前の変更
- App Store・TestFlight でのアプリの配布、iOS の共有拡張、Android のアプリ、オフラインでの閲覧
- GitHub Actions からの Cloudflare への公開
