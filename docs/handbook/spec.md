## 何のためのものか

X・note・Qiita の投稿と記事を、カテゴリ付きのカードで見るブックマークツール。Portal の Tips の使い勝手を単独のツールにしたもの。一覧は GitHub Pages、追加は Chrome/Edge の拡張機能か iPhone アプリ（Expo Go）から行う。

## 画面と機能

- **一覧の画面**: サイドメニュー（すべて、カテゴリごとの件数と色、未分類、カテゴリの追加・並べ替え・削除）、検索（NFKC でそろえ、空白区切りの語をすべて含む）、サイトの絞り込み。絞り込みと検索語は URL のクエリに残る。
- **カード**: カテゴリ、サイト、画像、タイトル、本文（6行で折りたたみ）、作者、日付、元ページへのリンク、カテゴリの変更、削除。
- **拡張からの追加**: ツールバーのボタン、右クリック、共有メニューに差し込んだ「Twimarkに追加」の3経路。カテゴリ（前回選んだもの）を選んで追加する。保存済みなら追加させない。取得できなかったときは本文を貼り付けて保存する。
- 画面からの追加は無い（課題 B-001）。
- **iPhone アプリ**: 下のタブの一覧・追加・カテゴリ・設定。一覧の画面と同じデータで、絞り込み・検索、カテゴリの変更・削除、カテゴリの追加・↑↓ での並べ替え・削除ができる。トークンがなければ読むだけ。
- **アプリへの追加**: X アプリの共有シートに置いた iOS のショートカットが `<アプリの URL>/--/add?url=<ポストの URL>` でアプリを開く。X の「リンクをコピー」からの貼り付けでも追加できる。カテゴリ・保存済み・本文の貼り付けの扱いは拡張と同じ。

## 対象のURLと取得元

| サイト | URL | 取得元 |
|---|---|---|
| X | `x.com/<handle>/status/<ID>`（twitter.com なども） | fxtwitter |
| note | `note.com/<ユーザー>/n/<キー>` | 記事の HTML の JSON-LD と OGP |
| Qiita | `qiita.com/<ユーザー>/items/<ID>` | 記事の HTML の JSON-LD と OGP |

要約は持たない。

## データの持ち方

- 正本は公開リポジトリの `data/bookmarks.json`。GitHub REST API で読み書きし、1回の書き込みが main への1コミットになる。
- 形は `{ version: 1, categories, bookmarks }`。1件は `id`（`x:<ID>` など）、サイト、URL、作者、投稿日、タイトル、本文、画像・動画のサムネイル、カテゴリ、保存日。
- カテゴリは30個まで、名前は20文字まで。既定は Portal の Tips と同じ6つ。削除したカテゴリのブックマークは「未分類」に出る。
- 閲覧はトークンなし（未認証の GitHub API、IP ごとに1時間60回まで）。編集にだけトークンが要る。

## しないこと

- 要約、画面からの追加、ストアでの拡張の公開
- App Store・TestFlight でのアプリの配布、iOS の共有拡張、Android のアプリ、オフラインでの閲覧
