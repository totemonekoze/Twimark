## 何のためのものか

X・note・Qiita の投稿と記事を、カテゴリ・サブカテゴリ付きのカードで見るブックマークツール。Portal の Tips の使い勝手を単独のツールにしたもの。一覧は Cloudflare Workers の画面と iPhone アプリ（Expo Go）で、どちらも同じ機能を持つ。追加は一覧の画面・アプリ・Chrome/Edge の拡張機能から行う。ブックマークは利用者ごとに別で、ほかの人のものは見えない。利用者は管理者の招待リンクからだけ増やせる。

## 画面と機能

- **ログイン**: ID とパスワード。パスキーを任意で足せ、パスキーがある ID ではパスキーを先に求める（「パスワードでログイン」も残る）。最初の1人が管理者として登録し、そのあとは管理者の招待リンク（1回きり、3日）からだけ登録できる。パスワードの失敗が15分に5回に達すると15分止める。
- **画面の作り**: Apple の HIG に沿う。縦長（スマートフォン、縦長の窓）の一覧の画面とアプリは同じ作りで、上のバーなし、下の真ん中のボタンで開くメニュー（一覧・カテゴリ・設定）、右下の追加の「＋」、大きな見出し、シート、アクションシート。横長の一覧の画面はサイドバー。ライトとダークは端末の設定に従い、動きを減らす設定では移動と拡大縮小をやめる。値は `src/shared/theme.js` の1か所。アクセント（既定は抹茶の黄緑）とカテゴリの色は利用者が選べ、Web とアプリで共通。
- **一覧**: 検索（NFKC でそろえ、空白区切りの語をすべて含む）、カテゴリとサブカテゴリのチップ（横長はサイドバー。件数と色、未分類）、サイトのセグメント。一覧の画面では絞り込み・検索語・タブが URL のクエリに残る。
- **カテゴリ**: 行を押すとその絞り込みの一覧へ。「編集」でカテゴリ・サブカテゴリの追加、ドラッグでの並べ替え、削除。ドラッグでほかのカテゴリの行に半分以上重ねると、カテゴリはその下のサブカテゴリに、サブカテゴリはそこへ移る（ブックマークもつく）。サブカテゴリはカテゴリに戻せる。
- **一覧の行**: 左に画像（ないときはカテゴリの色の四角に頭文字）、右にカテゴリ（`カテゴリ › サブカテゴリ`）、サイト、タイトル、本文（2行）、作者、日付。押すと元ページ、「…」で全文を読む・カテゴリとサブカテゴリの変更・元ページ・削除。
- **設定**: アクセントの色、パスキーの追加・削除、パスワードの変更、拡張・アプリの端末のトークンの発行・取り消し、招待リンクの作成・取り消し（管理者だけ）、自分のログインの履歴（成功と失敗、30日）、ログアウト。アプリでも同じ（パスキーの追加は Web の画面をアプリ内で開いて行う）。
- **追加**: 一覧の右上の「＋」のシートで URL を入れる（貼り付け、一覧の画面は `/?add=<URL>`、アプリは共有シートからも）。下見は Worker の `/api/meta` が取得する。カテゴリとサブカテゴリ（前回選んだ組）を選んで追加する。保存済みなら追加させない。取得できなかったときは本文を貼り付けて保存する。
- **拡張からの追加**: ツールバーのボタン、右クリック、共有メニューに差し込んだ「Twimarkに追加」の3経路。中身は追加のシートと同じ（下見は拡張が自分で取得する）。拡張は一覧の画面で発行した拡張のトークンで認証し、設定は変えられない。
- **iPhone アプリ**: ログインは一覧の画面をアプリ内の認証の画面で開いて行い（パスキーが使える）、予備に ID とパスワードだけのログインがある。アプリのトークンは設定も変えられる。共有シートの iOS のショートカットが `<アプリの URL>/--/add?url=<ポストの URL>` でアプリを開くと追加のシートが出る。

## 対象のURLと取得元

| サイト | URL | 取得元 |
|---|---|---|
| X | `x.com/<handle>/status/<ID>`（twitter.com なども） | fxtwitter |
| note | `note.com/<ユーザー>/n/<キー>` | 記事の HTML の JSON-LD と OGP |
| Qiita | `qiita.com/<ユーザー>/items/<ID>` | 記事の HTML の JSON-LD と OGP |

要約は持たない。

## データの持ち方

- 正本は Cloudflare D1 の `twimark`。ブックマークは1件1行で、カテゴリ、サブカテゴリ、利用者、パスキー、セッション（Cookie と端末のトークン。端末のトークンはアプリか拡張かの印を持つ）、招待（値の SHA-256 だけ）、ログインの履歴（30日）も D1 に置く。
- 1件は `id`（`x:<ID>` など）、サイト、URL、作者、投稿日、タイトル、本文、画像・動画のサムネイル、カテゴリ、サブカテゴリ（任意）、保存日。
- 色: アクセントは利用者ごと（`users.accent`）、カテゴリの色はカテゴリごと（`categories.color`。決まった色の名前か `#RRGGBB`、なしは並び順）。
- カテゴリは30個まで、サブカテゴリは1つのカテゴリに30個まで、名前は20文字まで。既定のカテゴリは Portal の Tips と同じ6つ。
- 削除したカテゴリのブックマークは「未分類」に出て、そのサブカテゴリは消える。削除したサブカテゴリのブックマークはカテゴリの直下に戻る。
- 読み書きはログインした利用者が自分の分だけ。リポジトリにはブックマークを置かない。

## しないこと

- 要約、ストアでの拡張の公開、拡張の画面の作り直し（HIG の作りは一覧の画面とアプリだけ）
- 利用者の削除・停止・役割の変更、招待のメール送信、パスワードの再設定のメール、カテゴリ・サブカテゴリの名前の変更
- App Store・TestFlight でのアプリの配布、iOS の共有拡張、Android のアプリ、オフラインでの閲覧
- GitHub Actions からの Cloudflare への公開
