# Twimark：一覧の刷新、ボトムメニュー、追加のボタン、色の設定

- 定義日: 2026-10-24
- 状態: reviewed
- 定義: Claude Code（2026-10-24）
  - 指示: 「ブックマーク一覧を、プロのUIデザイナーとして使いやすく、かつオシャレに刷新してほしいです。下部のタブをボトムメニュー化できませんか？ ブラウザ接続のスマホレイアウト、アプリ時、ブックマーク一覧をひらいているときに、"一覧"タブをタップしたらブックマーク一覧の最上部へスクロールするようにしてください。各ページのヘッダーは不要です。スクロールしてもヘッダーを出さないようにします。カテゴリと設定画面の最上部が画面より上に行ってしまいます。右下に〇の中央に＋が描かれている感じで、ツイートの追加ボタンを出すようにし、ヘッダー右上の追加ボタンは廃止。カテゴリのサブカテゴリ化を、ドラッグ中にカテゴリ同士が重なったタイミングにしてください。選択中などを示す緑色を、rgbとかカラーサークルから任意で設定で設定できるようにしてください。デフォルトは抹茶っぽい黄緑。カテゴリの色を設定できるようにしてください。」
  - その後の回答:
    - ボトムメニューの形: 「ボタン1つで開くメニュー」
    - 一覧の方向: 「画像が主役で、すっきりしたリスト」（選択肢の「画像が主役のカード」と「すっきりしたリスト」を合わせたもの）
    - 色の保存先: 「利用者ごと（Web とアプリで共通）」
    - カテゴリの色: 「決まった色と自由な色の両方」

## 目的

- **一覧を見やすく、きれいに:** カードを、画像が主役の、すっきりした1件1行のリストにする。
- **画面を広く使う:** 上のバー（ヘッダー）と下のタブバーをなくす。画面の移動は、下のボタン1つで開くメニューにする。追加は右下の丸い「＋」にする。
- **細かな直し:**
  - メニューで「一覧」を選ぶと、一覧の最上部へ送る。
  - カテゴリと設定の画面の最上部が、画面の外に出ないようにする。
  - カテゴリのサブカテゴリ化は、ドラッグ中の行がほかのカテゴリの行に重なったときにする。
- **色を選べるようにする:** アクセント（選択中などの色。既定は抹茶の黄緑）と、カテゴリごとの色を選べるようにする。Web とアプリで共通に保存する。

縦長の一覧の画面とアプリは、今と同じく同じ作りにする（定義 2026-10-22-001）。

## 前提

- 定義 2026-10-23-001 は公開済み（`1bde3e3`）。
- アプリは Expo Go（SDK 57）。足す依存は Expo Go に入っているもの（`expo-linear-gradient`）だけ。

## 方法

### 画面の外枠（縦長の一覧の画面とアプリ）

- **ヘッダーをなくす:** 上のバー（小さな見出しと右上のボタン）を出さない。送っても出さない。
  - 大きな見出しは、内容の一番上に置いたまま、内容と一緒に送る。
  - 内容は安全領域の上端（`env(safe-area-inset-top)`、アプリは `useSafeAreaInsets().top`）から始める。
- **最上部が画面の外に出る直し:** アプリの `contentInset`・`contentOffset` で空ける作りをやめ、内容の `paddingTop` で空ける。引っぱって再読み込みは、一覧の一番上で出る。
- **右上のボタンの移り先:**
  - 一覧の「＋」→ 右下の丸いボタン
  - Web の再読み込み → メニュー
  - カテゴリの「編集」→ 大きな見出しの行の右
  - ログインの履歴の「‹ 設定」→ 大きな見出しの上の行
- **ボトムメニュー:**
  - 画面の下の中央に、角の丸いボタンを1つ浮かべる。中身は今の画面のアイコンと名前（例: 「☰ 一覧」）。地は半透明の素材、影を付ける。下の安全領域の分だけ上げる。
  - 押すと、下からメニューのシートが出る。
    - 項目は「一覧」「カテゴリ」「設定」（アイコン付き。今の画面にチェック）と、Web だけ「再読み込み」。
    - 選ぶと移ってシートを閉じる。アプリは選んだときに触覚を返す。
  - 今「一覧」を開いていて「一覧」を選ぶと、閉じたあとに一覧の最上部へ滑らかに送る（動きを減らす設定では、すぐに）。アプリは、iOS のステータスバーを押したときの最上部への送りも効くようにする（一覧のリストだけ `scrollsToTop`）。
- **追加のボタン:**
  - 右下に直径 56 の丸いボタン（アクセントの地、中央に「＋」）を浮かべ、ボトムメニューと高さをそろえる。影を付け、押すと縮む。
  - 一覧の画面にだけ出す。押すと今の追加のシートを開く。
  - 読み上げ名は「追加」。
- 空の一覧の「追加」のボタンはそのまま残す。
- 下の浮いたボタンに最後の行が隠れないよう、内容の下に余白を取る。

### 横長の一覧の画面

- 左のサイドバーは今のまま（画面の移動はサイドバー）。ボトムメニューは出さない。
- ヘッダーの右上のボタン（再読み込み・追加）はなくす。追加は右下の丸い「＋」、再読み込みはサイドバーの下（「設定」の上）に置く。

### 一覧の行（画像が主役の、すっきりしたリスト）

カードの枠をやめ、1件1行のリストにする。

```
┌──────────┐ ●AI活用 › プロンプト · X        ⋯
│          │ タイトル（太字、2行まで）
│  画像    │ 本文（2行まで）
│ 104×104  │ jack · 10/22
└──────────┘
───────────────────────────────────────────（区切り）
```

- **画像:** 左に 104×104 の角丸（12）の正方形で切り抜いて出す。
  - 複数あれば右下に「+N」を出す。動画のサムネイルなら左下に再生のしるし。
  - 読めなかったときと、画像のないときは、同じ大きさの四角を代わりに出す。カテゴリの色の地に、サイトの頭文字（X、n、Q）を大きく出す。
- **文字:**
  - 1行目: カテゴリの点と名前（`カテゴリ › サブカテゴリ`。押すとカテゴリの変更）、サイト、右端に「…」。
  - タイトル（2行まで、太字）、本文（2行まで）。タイトルのないもの（X のポスト）は、本文を4行まで、タイトルと同じ太さで出す。
  - 最後の行: 作者と日付。
- **区切り:** 行の間は細い線（画像の右端から）。行の上下の余白は 14。行を押している間だけ、地を薄く塗って少し縮む。
- **押したとき:** 元のページを開く（今と同じ）。
- **「…」のメニュー:**
  - 「全文を読む」を足す。下からのシートで、画像（すべて）、タイトル、本文の全部、作者、日付、「元のページを開く」を出す。
  - 一覧での「続きを読む」はやめる。
- **幅:** 縦長は1列。横長の一覧の画面は、幅に合わせて2列か3列（1列の幅は 420 以上）。
- **上の絞り込み:** 検索、チップ、セグメントは今のまま。並べる間隔と行との余白は、行に合わせて直す。
- **読み込み中:** 行の形の淡い四角（スケルトン）を5行出す。今の回るしるしの代わり。

### カテゴリの重なりでサブカテゴリにする

今は指の位置で入れ先を決めている（Web は指が行の上下の真ん中半分、アプリも同じ）。これを、動かしている行と入れ先の行の重なりで決める形に替える。

- **動かしている行の見せ方（Web とアプリで同じ）:** 指に付いて動かす。ほかの行はずらさず、入る位置に線を出す。
  - アプリは今もこの形。
  - Web は今、行の並びを入れ替えながら動かしている。これをアプリと同じ形に替える。カテゴリを動かす間にサブカテゴリの行を隠すのはやめ、カテゴリの塊（カテゴリの行とそのサブカテゴリ）ごとに動かす。
- **入れ先:** 動かしている行が、ほかのカテゴリの行と、その行の高さの 50% 以上重なったら入れ先にする。2つ以上と重なるときは、重なりの大きいほう。
  - 光らせ方、「〇〇の下に入れる」の文、置き場、確認は今のまま。
  - 重なりが 50% を切ったら、入れ先を外して並べ替えに戻る。
- **置き場（「カテゴリにする」）:** 動かしているサブカテゴリの行が、置き場と重なったら入れ先にする。

### アクセントの色

- **既定:** 抹茶の黄緑 `#8DB255`。今の `colors.accent`（くすみ緑）は、既定のアクセントに置き換える。
- **選んだ色から作るもの:** `src/shared/theme.js` の `accentSet(hex)` が、ライトとダークのそれぞれについて次を返す。Web とアプリは同じ関数を使う。
  - `accent`（地として塗る色＝選んだ色）
  - `onAccent`（その上の文字。白か黒の、コントラストの大きいほう）
  - `accentText`（面の上の文字・リンク・アイコンに使う色。選んだ色の色相のまま明るさだけを変え、面と地の両方に対して 4.5:1 以上になるところまで、ライトでは暗く、ダークでは明るくする）
  - `accentSoft`（選んだ色を面に 18% 混ぜた淡い地）
  - `accentInk`（`accentSoft` の上の文字。`accentText` と同じ決め方）
- **使い分け:** 今アクセントを文字の色に使っているところ（リンク、文字のボタン、アイコン、チェック）は `accentText` にする。地に塗るところ（選んだチップ、追加のボタン、ボタン）は `accent` と `onAccent` にする。
- **保存:** 利用者ごとに D1 の `users.accent`（`#RRGGBB` か、既定なら NULL）。`/api/data` が `accent` を返す。
- **変える操作:** `POST /api/ops { op: 'setAccent', args: ['#RRGGBB' | null] }`。形が違えば `invalid_color`。
  - データの操作と同じく、拡張のトークンでも使える（見た目の好みなので、設定の操作ではなくデータの操作として扱う）。
- **Web:**
  - 読み込んだ `accent` から CSS 変数（`--accent` など5つのライトとダーク）を `:root` に入れる。
  - 次に開いたときの色のちらつきを防ぐため、最後の値を `localStorage` に置き、`app.js` の最初で先に入れる（読めなくても既定の色で動く）。
- **設定の画面に「外観」の段を足す（設定の一番上、アカウントの下）:**
  - 「アクセントの色」の行。今の色の丸と、色の名前（`#RRGGBB`）を出す。押すと色を選ぶシートを開く。
  - 色を選ぶシートの中身:
    1. 上: 見本（選んだチップ・ボタン・リンクの見え方）
    2. 色を選ぶ部分
       - Web は `<input type="color">`（パソコンでは四角と色相の帯と RGB、iPhone の Safari ではカラーサークルなどの OS の選び方が出る）
       - アプリは、彩度と明るさの四角と、色相の帯（`expo-linear-gradient` で描き、指でなぞる）
    3. RGB の入力: 「R」「G」「B」の 0〜255 の欄と、`#RRGGBB` の欄（どれを変えても互いにそろえる）
    4. よく使う色: 抹茶（既定）、今のくすみ緑、青、紫、赤、橙、灰の7つの丸
    5. 「既定に戻す」
  - 「保存」で `setAccent` を送り、すぐに画面の色を替える。保存の前は見本だけを替える。

### カテゴリの色

- **保存:** `categories.color`。
  - 値は決まった11色の名前（`teal` など）か `#RRGGBB`。
  - NULL は今と同じく、並び順で決める（`view.js` の `toneOf`）。
- **変える操作:** `POST /api/ops { op: 'setCategoryColor', args: [カテゴリ, 色 | null] }`。ないカテゴリは `invalid_category`、形が違えば `invalid_color`。
- **`/api/data`:** `categoryColors: { [カテゴリ]: 色 }` を足す（色を決めたカテゴリだけ）。
  - `categories` は今と同じ文字列の配列のままにする（拡張が読む形を変えない）。
- **移す操作との関係:**
  - `nestCategory` でサブカテゴリになったカテゴリの色は消える。
  - `promoteSubcategory` でできたカテゴリは NULL。合わせた先が今あるカテゴリなら、その色のまま。
- **自由な色の表示:** `#RRGGBB` は `theme.js` の `toneSet(hex)` で、ライトとダークそれぞれの [文字, 地] を作る。
  - 地: 選んだ色を面に混ぜた淡い色（ライト）・暗い色（ダーク）
  - 文字: 同じ色相で、地に 4.5:1 以上
  - 点と、画像のない行の四角は、選んだ色そのもの
  - Web は、要素に `data-tone="custom"` と `--tone-l`・`--tone-bg-l`・`--tone-d`・`--tone-bg-d` を付け、CSS でライトとダークを切り替える。
- **画面:** カテゴリの「編集」の間、カテゴリの行の色の点を押すと、色を選ぶシートを開く（アクセントと同じシート）。
  - 決まった11色が上の段に並び、今の色にチェックが付く。
  - その下に「自由な色」（アクセントと同じ選び方）と「自動（並び順）」を出す。
  - 選ぶとすぐに `setCategoryColor` を送る。自由な色だけは「保存」で送る。

### Web とアプリで同じにすること

- メニュー、「＋」、一覧の行、全文のシート、色を選ぶシート、カテゴリの色の選び方の並びと名前は、Web とアプリで同じにする。
- 色を選ぶ部分だけは、Web は OS の選び方、アプリは自作の四角と帯にする（Expo Go に OS の色の選び方を出す部品がないため）。

## テスト

`self-test.mjs` に、次を確かめる試験を足す。

- `0004` が当たり、今ある行は `accent` と `color` が NULL になる。
- `setAccent`:
  - `#RRGGBB` を保存し、`/api/data` が返す。
  - null で既定に戻る。
  - 形の違うもの（`red`、`#12345`、`#GGGGGG`、数）は `invalid_color`。
  - ほかの利用者に触れない。
- `setCategoryColor`:
  - 名前と `#RRGGBB` を保存し、`categoryColors` で返す。null で消える。
  - ないカテゴリは `invalid_category`、決まった11色にない名前は `invalid_color`。
  - `nestCategory` のあとは色が消え、`promoteSubcategory` で合わせた先の色は残る。
- `accentSet`・`toneSet`:
  - 決まった色と、ばらばらな色（0〜255 の RGB を一定の歩みで回したもの、数百通り）のどれでも、次がライトとダークの両方で 4.5:1 以上になる。
    - `accentText` と面と地
    - `onAccent` と `accent`
    - `accentInk` と `accentSoft`
    - `toneSet` の文字と地
  - 既定の `#8DB255` の値が、決まった値になる（ずれたら気づけるように）。
