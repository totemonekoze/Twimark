## 目的

- **下のタブ:** 下に浮かぶ丸いボタン（今は「メニュー」を開く1つのボタン）を、一覧・カテゴリ・設定を直接選べるタブにする。
- **送りで消す:** 送っている間は、下のタブに加えて右下の「＋」も消す。止まってから出るまでを短くする。
- **色のなぞり（アプリ）:** 色のシートで、四角・色相の帯・色見本を、押したまま指を動かして選べるようにする。
- **カードの長押し（アプリと縦長の Web）:** カードを長押しすると持ち上がり、下に出るカテゴリの置き場へ動かして離すと、カテゴリが変わる。
- **3D Touch（アプリと縦長の Web）:** カードを強く押すと、今のカードのメニュー（カテゴリを変える・元のページを開く・削除）を出す。
- **横長の Web のサイドバー:** 「編集」中の詰まりをほどき、右下の「＋」を一覧の近くに移す。
- **右クリック（Web）:** カテゴリ・サブカテゴリの行の右クリックで、カテゴリの編集のメニューを出す。
- **入れ子のドラッグ（Web）:** カテゴリをほかのカテゴリの行に重ねて離すとサブカテゴリになる操作（定義 `2026-10-23-001`）を、Web で確実に効くようにする。

## 前提

- 下のボタン（定義 `2026-10-24-001`・`002`）:
  - アプリ（`App.js` の `BottomBar`）と縦長の Web（`index.html` の `.menu-pill`）は、今の画面の名前の丸いボタンを1つ出し、押すとメニューのシートで画面を選ぶ。
  - 送り始めると丸いボタンだけをフェードで消し、止まって 0.5 秒で出す（アプリは `ScrollHideContext`、Web は `body.scrolling`）。右下の「＋」は消えない。
  - 横長の Web は丸いボタンを出さず、「＋」は画面の右下の角。
- カード:
  - アプリの長押しは今、カードのメニュー（`ActionSheetIOS`）を出す。カードの右上の「…」も同じメニュー。カテゴリの札を押すとカテゴリを変えるシート。
  - Web のカードも「…」（`data-menu`、`cardMenu`）で同じメニュー。
- 色のシート（`ColorSheet.js`）は四角と色相の帯を `PanResponder` でなぞれるが、定義 `002` の完了報告で「なぞったときの動きは実機で未確認」。利用者の指摘では、押したままでは編集できない。
- カテゴリの入れ子のドラッグは、Web（`app.js` の `startDrag`）とアプリ（`CategoriesScreen.js`）の両方に、「編集」中のつまみ（☰）から使える形である。Web で効かない条件は、まだ分かっていない。
- 3D Touch のある iPhone は iPhone 6s〜XS（XR・11 以降と SE 第2世代以降にはない）。ない機種では強く押す操作は起きないので、メニューはカードの「…」から出す。
- 依存パッケージは足さない（React Native の `PanResponder`・`Animated`・`LayoutAnimation`、Web の Pointer Events で作る）。

## 方法

### 1. 下のタブ（アプリと縦長の Web）

- 今の丸いボタンの形（角丸 24、すりガラスの素材、影）はそのままに、中を3つのタブにする。
  - 左から「一覧」（アプリ `books.vertical`、Web は今のアイコンの組から近いもの）、「カテゴリ」（`folder`）、「設定」（`gearshape`）。アイコンの下に名前（小さめ、600）。
  - 1つのタブは幅 72〜88px、高さ 48px（押せる範囲は 44px 以上）。
  - 選んでいるタブは、アクセントの薄い地の丸い札を後ろに敷き、文字とアイコンをアクセントの濃い色にする。札は選び直すと横へすべって動く（約 0.22 秒。動きを減らす設定ではすべらせない）。
  - アプリは触覚の選択を返す。読み上げは `tablist`／`tab`（Web は `role="tablist"`、`aria-selected`）。
- 選んでいる「一覧」をもう一度押すと、今と同じく最上部へ送る。
- 今の画面を選ぶメニューのシート（アプリの `Menu`、Web の `dialog[data-menu-sheet]` と `[data-menu-open]`）はやめる。
- 横長の Web は今と同じく、タブを出さない（サイドバーが同じ働き）。

### 2. 送りで消す・出す（アプリと Web）

- 送り始めたら、下のタブと右下の「＋」を一緒に、約 0.15 秒のフェードで消し、押せなくする。
- 送りが止まって **0.25 秒**（今は 0.5 秒）で、約 0.2 秒のフェードで出す。
- 画面を替えたときは、すぐに出す（今と同じ）。
- 横長の Web は「＋」の置き場所が変わる（下の 6.）ので、送りでは消さない。

### 3. 色のなぞり（アプリ）

- **原因を確かめる:** 実装者は Expo Go で、四角・帯を押したまま縦横に動かして、途中で止まる・シートが送られる・何も起きない、のどれかを確かめる。考えられる原因は、送りを止める `scrollEnabled` が状態の書き換えの後でしか効かず、その前にシートの送りが指を取ってしまうこと。
- **直し:**
  - 見本・四角・色相の帯を、シートの送りの外（シートの上側に固定）に置く。RGB・#RRGGBB・よく使う色など、残りだけを送れるようにする。これで送りと指の取り合いがなくなる。
  - 色相の帯の押せる高さを 44px にする（見た目の帯は今の 20px のまま）。
  - **色見本（決まった色・よく使う色・白黒）を押したまま横に動かして選べる**ようにする。並び全体で1つのなぞりを受け、指の下の見本を選び、変わるたびに触覚の選択を返す。
    - 「よく使う色」は指の下の色を選ぶ（保存は「保存」で今と同じ）。
    - カテゴリの「決まった色」とアクセントの文字の「白・黒」は、今は押すとすぐ保存して閉じる。なぞりでは選ぶだけにし、離したときに保存して閉じる（押しただけのときも今と同じに保存して閉じる）。
  - 四角と帯は、触れた瞬間の位置の色にし、離すまで指に付いてくる（今と同じ考え方）。
- Web の色の画面は変えない（回答が「アプリだけ」）。

### 4. カードの長押しでカテゴリを変える（アプリと縦長の Web）

- **始まり:** カードを約 0.4 秒押し続け、その間に指が 10px 以上動かなかったら始める（先に動いたら送りとして扱う）。触覚の中くらいの衝撃を返す。
- **持ち上げ:**
  - 元のカードは薄く（不透明度 0.3）なり、その場に残る。
  - カードの写し（画像と題名だけの小さい形、元の約 0.55 倍）が、少し大きくなってから指の下に付いて動く。影を濃くする。
  - 一覧の送りは止める。下のタブと「＋」は消す。
- **カテゴリの置き場:** 画面の下から置き場がせり上がる（高さは画面の 45% まで）。
  - 見出し「カテゴリへ移す」。中はカテゴリの札を2列で並べる（色の点、名前、件数）。最後に「未分類」。
  - 今のカテゴリ（サブカテゴリにいるときはその親）の札は「今のカテゴリ」と小さく出し、置き先にしない。
  - 写しが札に重なったら、札を少し大きくしてアクセントの枠を付け、触覚の選択を返す。
  - **サブカテゴリ:** サブカテゴリを持つカテゴリの札に 0.6 秒重ねると、置き場の中がそのカテゴリのサブカテゴリの札に替わる（先頭は「〇〇（直下）」、上に「‹ カテゴリ一覧」の戻る札）。戻る札に 0.6 秒重ねると元に戻る。
  - 札が置き場に収まらないときは、置き場の上端・下端の 48px に重ねている間、置き場の中を送る。
- **離したとき:**
  - 札の上: 写しが札へ縮みながら吸い込まれて消え（約 0.22 秒）、触覚の成功を返し、`ops.setCategory(id, category, sub)` で保存する。元のカードはカテゴリの札を新しい色と名前に替えて戻る。今の絞り込みに合わなくなったら、カードは並びから抜ける（アプリは `LayoutAnimation`、Web は View Transitions）。
  - 札の外: 写しが元のカードの位置へばねで戻り、置き場が下がる。何も変えない。
  - 保存に失敗したら、今と同じ文で知らせ、読み直す。
- **動きを減らす設定:** 拡大・縮小・ばねをやめ、フェードだけにする。
- **読み上げ:** カードに「カテゴリを変える」の操作（アプリは `accessibilityActions`）を足す。長押しの説明文（`accessibilityHint`）は「長押しで持ち上げてカテゴリへ移す」に替える。今のカテゴリの札と「…」はそのまま。
- **縦長の Web の違い:**
  - 長押しは指・ペンでも、マウスでも同じ（Pointer Events）。カードの画像とリンクの、ブラウザの長押しのメニュー（`-webkit-touch-callout`）と文字の選択を止める。
  - 置き場と写しは、ページの上に重ねる要素で作る。
- 横長の Web のカードの長押しは、この定義では変えない。

### 5. 強く押したときのメニュー（3D Touch。アプリと縦長の Web）

- 押している間の押す強さ（アプリはタッチの `force`、Web は `TouchEvent` の `touches[0].force`。どちらも 0〜1）が **0.6** を超えたら、長押しを取りやめて、触覚の強めの衝撃を返し、今のカードのメニュー（カテゴリを変える・元のページを開く・削除）を出す。
- 強さに合わせて、カードを 1.0 から 0.96 まで少し縮める（メニューが出る手前の合図）。
- 3D Touch のない機種とブラウザでは強さが 0 のままなので、何も起きない。メニューはカードの「…」から出す（今と同じ）。
- 長押しではメニューを出さない（4. の移動だけ）。

### 6. 横長の Web のサイドバーと「＋」

- **「＋」の置き場所:** 横長では右下の「＋」を出さず、一覧の上の並び（検索の欄とフィルターのボタンの右）に「＋ 追加」のボタン（アクセントの色、高さ 36px）を置く。押すと今の追加の画面を開く。
- **「編集」中のサイドバー:**
  - 編集中の行の高さを 34px から 40px にする。削除のボタン（32px）、色の点（28px）、名前の間を 8px あける。
  - カテゴリの塊（カテゴリの行と、続くサブカテゴリと「サブカテゴリを追加」）の上に 6px の間をあける。
  - 「サブカテゴリを追加」はサブカテゴリの名前の位置にそろえ、文字を小さめ（footnote）、行の高さ 32px にする。
  - 「カテゴリを追加」は、上に区切り線と 12px の間をあけ、ほかの行と分ける。
  - 編集していないときの見た目は変えない。

### 7. 右クリックのメニュー（Web）

- サイドバーとカテゴリの画面の、カテゴリ・サブカテゴリの行を右クリック（`contextmenu`）すると、押した場所に小さなメニューを出す。「編集」中でもそうでなくても出す。
  - カテゴリ: 「サブカテゴリを追加」「色を変える」「ほかのカテゴリの下に入れる…」（今の `moveMenu`）「削除」（赤）。
  - サブカテゴリ: 「カテゴリにする」「ほかのカテゴリへ移す…」（今の `moveMenu`）「削除」（赤）。
  - 「すべて」と「未分類」は、ブラウザのいつものメニューのまま。
  - Shift を押しながらの右クリックは、ブラウザのいつものメニュー（新しいタブで開くなど）を出す。
- メニューは `ui.js` に、押した位置に出す小さな部品として作る（`popover` で一番上に重ね、外を押す・Escape・送りで閉じる。↑↓ と Enter で選べる）。画面の端からはみ出さない位置にずらす。
- 中の操作は、今の関数（`openCategoryAdd`、`openColorSheet`、`moveMenu`、`askDeleteCategory`、`promote`）を呼ぶだけにする。

### 8. 入れ子のドラッグ（Web）

- **原因を確かめる:** 実装者は内蔵ブラウザで、横長（マウス）と縦長（指の操作のまね）の両方で、「編集」中にカテゴリのつまみをほかのカテゴリの行へ動かし、光る・「〇〇の下に入れる」が出る・離すとサブカテゴリになる、を確かめる。効かない条件を見つけて直す。
- **あわせて直すこと:** 名前の行そのものをドラッグしても動かせるようにする。
  - 「編集」中: マウスで名前の行を押して 6px 以上動かしたら、つまみと同じドラッグにする。押して離すだけなら、今と同じく移し先のメニュー。
  - 横長の「編集」していないとき: マウスでカテゴリ・サブカテゴリの行を押して 6px 以上動かしたら、同じドラッグ（並べ替え・入れ子・カテゴリにする）にする。押して離すだけなら、今と同じく絞り込み。リンクのドラッグ（`draggable`）は止める。
  - 指の操作では、送りと取り合わないように、今と同じくつまみからだけ。
- 入れ先の決め方（行の高さの半分以上の重なり）と保存のしかたは、定義 `2026-10-23-001` のまま。
