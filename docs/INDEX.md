# Twimark Project Knowledge

このプロジェクトだけで成り立つKnowledgeの目録。1行1件。作業記録（定義、レビュー）は `INDEX-records.md` にある。

- **現行要件** — `requirements/current-mvp.md` — 画面、拡張、データの形、対象のURL
- **共有メニューの目印** — `knowledge/share-menu-dom.md` — X、note、Qiita、共有ボタン、role=menu、data-engagement-action、shareMenuDesktop、o-shareBooster、Escape、content script
- **運用ルール** — `requirements/project-rules.md` — ビルド、テスト、配信、公開リポジトリの安全
- **仕様書（要約）** — `handbook/spec.md` — 最初に読む、画面、機能、対象のURL、データの形、しないこと
- **作業書（要約）** — `handbook/operations.md` — 最初に読む、ビルド、テスト、拡張の読み込み、配信、トークンの発行
- **設定詳細（要約）** — `handbook/configuration.md` — 最初に読む、配信先、権限、CSP、トークンの置き場所、ワークフロー
